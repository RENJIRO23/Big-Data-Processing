# About This Project
Proyek ini mengolah dataset OPENAQ 2025 menggunakan arsitektur pemrosesan data batch. Tujuannya adalah untuk memahami pola lonjakan polusi, memprediksi tingkat risikonya menggunakan Machine Learning, dan memberikan insight bagi pemerintah kota untuk kebijakan publik yang lebih sehat.
# Main Tech
- Big Data Framework: Apache Spark (PySpark)
- Machine Learning: Spark MLlib (Random Forest Classifier)
- Visualisasi: Matplotlib, Seaborn
- Environment: Google Colab
# Main Findings
- Akurasi Model: Model Random Forest berhasil memprediksi tingkat kategori polusi harian dengan akurasi 87%.
- Jam Kritis: Puncak polusi terjadi setiap pukul 15:00 - 17:00, sangat berkorelasi dengan emisi kendaraan saat jam pulang kerja.
- Solusi Aksi: Disarankan untuk mengoptimalkan rute lalu lintas sore hari dan menerapkan zona rendah emisi di dekat sekolah atau fasilitas publik.
